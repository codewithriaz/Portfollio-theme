1. Installation

  1. In WordPress go to Appearance → Themes → Add New → Upload Theme, choose riaz-portfolio.zip, install and Activate.
  2. Go to Appearance → Riaz Portfolio and click Install & activate Riaz Portfolio Core. This companion plugin is bundled with the theme. It holds your content (services, projects, testimonials…) so nothing is lost if you ever change theme.
  3. On the same screen click Import starter content. It creates the 6 services and 5 FAQs from the design, a Home and a Blog page (set in Settings → Reading), the header and footer menus, and the logo. Existing items with the same title are never overwritten, so it is safe to run twice. Tick "Sample projects…" to also get example projects, a case study and pricing plans as drafts.
  4. Open Appearance → Customize and make it yours.

Requirements: WordPress 6.6 or newer (tested up to 7.1), PHP 7.4 or newer (tested on 8.2 and 8.5).

Manual plugin install: if the button cannot install plugins on your host, upload wp-content/themes/riaz-portfolio/plugins/riaz-portfolio-core.zip in Plugins → Add New → Upload Plugin.

2. Editing the homepage

Go to Appearance → Customize → Homepage Sections. Changes preview live; click Publish to save. You can also click the blue pencil icons in the preview to jump to a section's settings.

Order & visibility

Section Order & Visibility lists all 14 sections. Drag (or use the arrows) to reorder, untick to hide, and click the pencil to edit one. Sections without content hide themselves automatically: Portfolio stays hidden until you publish a project, Testimonials until you add a testimonial, and so on. Menu links to hidden sections are hidden too.

4. Theme Options

Appearance → Customize → Theme Options:

  • Brand Colors — eight colors; every gradient, glow and tint follows them. The block editor palette updates too.
  • Typography — body and heading fonts (Roboto is self-hosted; others load from Google Fonts), base size, heading weight.
  • Header — logo width, white pill behind the logo, sticky header, header button. Upload the logo and site icon in Site Identity.
  • Footer — brand name, description, column titles, copyright ({year} and {site} placeholders), back-to-top link, large wordmark.
  • Contact Details — email, phone, address, availability, form options.
  • Social Links — LinkedIn, X, Facebook, Instagram, YouTube, TikTok, GitHub, Dribbble, Behance, WhatsApp.
  • Layout & Animation — content width, section spacing, animations, custom cursor, scroll progress bar, page banner, breadcrumbs.
  • Blog — banner text, grid or list, sidebar, share links, author box, related posts.
  • Performance — per-block CSS loading and font preloading.
  • SEO, Analytics & Performance (from the plugin) — see section 9.

5. Menus & footer

Appearance → Menus has four locations: Primary menu (header, up to three levels with dropdowns), Footer — Column 1, Footer — Column 2 and Footer — Bottom links (e.g. Privacy Policy). Without a menu the header shows links to the homepage sections, column 1 shows section links and column 2 lists your services. The contact column uses your contact details.

To link to a homepage section, add a Custom Link such as https://yoursite.com/#services. The highlight pill follows the section in view while scrolling.

6. Pages, blog & templates

Inner pages get a dark banner with breadcrumbs and the title (H1). In the editor sidebar the Display options box lets you hide the banner, add a subtitle and choose the header style per page.

The homepage shows the sections when Settings → Reading uses "Your latest posts" or a static page with no content. If the front page has its own content (blocks, Elementor or Divi), that content is shown instead.

7. Gutenberg, Elementor & Divi

Block editor

Add the Theme Section block (category "Riaz Portfolio") and choose a section in the sidebar; the preview matches the live site. The Patterns tab has a full homepage, services page, about page, contact page and an intro block. Block style variations: Group → Card, Heading → Gradient, Image → Rounded & elevated, List → Check marks.

Elementor

Use the Full Width (no title) or Elementor Full Width template. Drag the Theme Section widget from the "Riaz Portfolio" category. Elementor Pro's Theme Builder can replace the header, footer, single and archive templates.

Divi

Install the Divi Builder plugin (the separate plugin, not the Divi theme). Choose the Full Width (no title) template. The builder is enabled on projects, case studies and services. Insert theme sections with a Code or Text module:

[riaz_section name="services"]
[riaz_section name="faq" id="questions"]
[riaz_contact_form]
[riaz_social style="light"]
[riaz_button label="Book a call" url="#contact" style="primary"]
[riaz_icon name="rocket" size="24"]

Section names: hero, marquee, about, stats, services, approach, portfolio, case_studies, testimonials, team, pricing, faq, cta, contact.

8. Contact form

The built-in form emails messages to Send form messages to, then the contact email, then the site admin email. It is protected by a nonce, a hidden honeypot field, a minimum fill time and a limit of three messages per visitor per ten minutes. Nothing is stored in the database.

  • Install an SMTP plugin (e.g. WP Mail SMTP) so emails are delivered reliably.
  • Prefer Contact Form 7, WPForms, Fluent Forms or Gravity Forms? Paste its shortcode in Form plugin shortcode.
  • With full-page caching, exclude the page with the form from the cache, or use a form plugin (cached security tokens expire after a day).

9. SEO & analytics

Riaz Portfolio Core prints the meta description, Open Graph and X cards, canonical links on archives and a JSON-LD schema graph: WebSite, Person or Organization (with your social profiles), WebPage, BreadcrumbList, BlogPosting, CreativeWork for projects, Article for case studies, Service and FAQPage. Edit it in Customize → Theme Options → SEO, Analytics & Performance.

If you install Yoast SEO, Rank Math, SEOPress, All in One SEO, Slim SEO or The SEO Framework, the built-in tags switch off automatically to avoid duplicates. Breadcrumbs, one H1 per page, semantic headings and clean permalinks (/portfolio/, /case-studies/, /services/) are built into the theme.

Add a GA4 measurement ID (G-XXXXXXXXXX) to enable Google Analytics. Logged-in editors are not tracked. If you need cookie consent, use a consent plugin that supports Google Consent Mode.

10. Performance

Out of the box: no jQuery on the front end, one deferred and minified script (≈5 KB gzipped), one minified stylesheet (≈14 KB gzipped), a self-hosted variable font with preload, responsive WebP images, lazy loading, the hero image preloaded with high priority, per-block CSS, and no layout shift. A local Lighthouse run scored 94 on mobile and 100 on desktop for performance, and 100 for accessibility, best practices and SEO.

On your live site, to reach 90+ on PageSpeed Insights:

  • Use hosting with HTTP/2 or HTTP/3, gzip or Brotli compression and browser caching (most managed WordPress hosts do this).
  • Add a page cache (LiteSpeed Cache, WP Rocket, W3 Total Cache or your host's cache).
  • Upload images at sensible sizes; WordPress creates responsive versions automatically. An image optimizer (WebP/AVIF) helps further.
  • Keep the number of plugins low.

11. Accessibility

Skip link, landmarks, one H1 per page, keyboard-operable menus (Escape closes the mobile menu and returns focus), visible focus outlines, labelled buttons and forms, screen-reader announcements for the project filter and copy-link button, and text contrast that meets WCAG AA. Every animation respects the visitor's "reduce motion" setting, and all content is visible without JavaScript. The custom cursor only appears for mouse users and can be turned off.

Please add alt text to images in the Media Library — the theme uses it automatically.

Child theme

Create riaz-portfolio-child with Template: riaz-portfolio. Any template part (for example template-parts/sections/about.php) can be copied into the child theme and edited. Assets are loaded with get_theme_file_uri(), so they can be overridden too.

Adding a section

add_filter( 'riaz_sections', function ( $sections ) {
	$sections['clients'] = 'Client logos';
	return $sections;
} );
// Then create template-parts/sections/clients.php in your child theme.

window.RiazTheme.init(element) initialises reveals, carousels, accordions, filters, counters and videos inside element — useful after inserting markup with AJAX. 13. Troubleshooting

Portfolio or case study pages show "Page not found"

Go to Settings → Permalinks and click Save once.

A section does not appear

Check it is ticked in Section Order & Visibility, and that it has content (for example a published project or testimonial). Hidden sections show a hint while you are in the Customizer.

The homepage shows my page content instead of the sections

Your front page (Settings → Reading) has content. Clear it, or assign the Homepage Sections template to that page.

The header is hard to read on a page

In the page editor's Display options box set Header style to Solid (or Transparent if the page starts with a dark section).

Contact form emails do not arrive

Install an SMTP plugin; many hosts block PHP mail.
