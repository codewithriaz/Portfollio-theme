A modern, fast and animated portfolio theme for consultants, marketers, freelancers and agencies.

== Description ==

Riaz Portfolio recreates a premium one-page portfolio design as a fully editable WordPress theme:

* Homepage sections: hero, "who I help" marquee, about, statistics, services, approach/process timeline, portfolio with category filter, case studies, video and written testimonials, team, pricing, FAQ, call to action and contact.
* Every section is edited, reordered or hidden in Appearance → Customize → Homepage Sections, with live preview.
* Brand colors, fonts, header, footer, contact details, social links, layout and animations in Appearance → Customize → Theme Options.
* Works with the block editor, Elementor (including Pro Theme Builder) and the Divi Builder. Page templates: Homepage Sections, Full Width and Blank Canvas.
* Fast: no jQuery on the front end, one deferred script, self-hosted variable font, responsive WebP images, lazy loading.
* Accessible: skip link, keyboard-friendly menus, visible focus styles, reduced-motion support, semantic landmarks and headings.

The bundled companion plugin, Riaz Portfolio Core, adds the content types (services, portfolio, case studies, testimonials, team, FAQs, pricing), the "Theme Section" block and Elementor widget, shortcodes, the contact form, SEO meta tags and schema, and the starter content importer. Install it from Appearance → Riaz Portfolio.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme, choose riaz-portfolio.zip and activate.
2. Go to Appearance → Riaz Portfolio and click "Install & activate Riaz Portfolio Core".
3. Click "Import starter content" to recreate the demo (services, FAQs, pages and menus).
4. Customize everything in Appearance → Customize.

See documentation.html in the theme folder for the full guide.

== Frequently Asked Questions ==

= How do I change the homepage text? =
Appearance → Customize → Homepage Sections. Click any section to edit it; changes preview live.

= How do I add services, projects or testimonials? =
Use the Services, Portfolio, Testimonials (and other) menus in the dashboard. They appear on the homepage automatically.

= Can I build pages with Elementor or Divi? =
Yes. Choose the "Full Width (no title)" template, then build normally. Insert any theme section with the "Theme Section" widget (Elementor) or [riaz_section name="services"] (Divi, classic editor).
